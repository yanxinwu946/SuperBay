# 工具工作台功能说明

## 目录快捷入口

顶部目录选择器保存常用目录，一次只展示、监听和搜索当前目录，不做跨目录聚合。通过「工具管理 → 快捷入口」添加、重命名、移除入口；移除入口不删除磁盘文件。

设置中的「工作区 → 管理快捷入口」也能管理目录。更改根目录时会重新扫描并清空当前筛选。

目录可多级嵌套，侧栏分类支持展开和收起。点击父分类会包含子分类条目，搜索覆盖整个当前工具目录。根目录直属文件也会收录。

含启动入口、工程配置或 Git 标记的工具文件夹作为完整工具保留，不继续展开其源码和依赖；普通文档文件夹可逐级浏览。隐藏目录、依赖目录和指向工具目录之外的目录链接会跳过。

## 工具环境、启动入口与配置

工具右键「运行环境」可绑定 Scoop 中具体版本的 Python、Java、Node，启动时只对当前工具生效。默认环境不受修改。

「识别启动入口」支持 Python、JAR、Node、EXE、批处理和 PowerShell。唯一候选可直接启动，多个候选需选择后保存。Python 工具存在 `.venv/Scripts/python.exe` 时优先建议项目环境。详情面板显示建议，命令仍可编辑。

工具右键「启动配置」可保存多套名称、命令、参数、管理员启动选项以及当前环境绑定。取消保存环境绑定时，新配置继承工具环境；已有配置可保留原绑定。工具环境版本变更后，如需更新配置快照，请重新保存对应配置。

## 快捷启动

Ctrl+P 打开快速启动面板，搜索范围仅为当前目录。方向键选择条目，下拉选择保存的启动配置，Enter 启动。界面提供启动配置和运行环境入口。Shift+Enter 临时输入参数，Ctrl+Enter 使用管理员权限按默认配置启动。

## 启动状态与日志

可执行命令通过独立控制台工作进程启动，不继承 GUI 的控制台句柄。界面显示启动、运行、退出、失败状态；「工具管理 → 运行记录」查看实时输出、错误和退出结果。窗口关闭到托盘不影响工具运行。

普通目录或没有可执行入口的文件交给 Windows 打开，此类操作只表示请求已提交，不宣称其关联应用处于运行状态。历史状态未知时会明确标出。

运行记录和日志在本地 `config/launches` 中保存；退出后仍可查阅。环境请求只保存覆盖项，不复制整个父进程环境，并在运行完成后移除。日志及自定义命令可能包含用户自己输入的信息。

## 健康检查

「工具管理 → 健康检查」检查路径、入口歧义、解释器和绑定版本。可重新选择启动入口、绑定环境或重新定位失效工具。自动检查不安装依赖或修改系统环境。缺失工具的元数据保留，供修复使用。

## 备份与迁移

「工具管理 → 备份与迁移」导出 ZIP：包含设置、工具元数据、统计、启动配置和环境绑定，不包含工具文件和运行日志。

导入先生成 `config/before-import-时间.zip`。同路径配置以备份为准，其他工具配置保留。可填写原目录、新目录，迁移路径前缀及环境根目录；自定义命令中写死的绝对路径需重新识别或编辑。工具文件需要自行复制到新电脑，绑定运行环境需要在本机实际安装。

主题与视图立即刷新；快捷键和窗口位置重启后生效。

## 验证

自动测试覆盖目录快捷入口与扫描隔离、入口识别与歧义、备份往返及目录迁移、无效备份保护、环境差异隔离、工作进程退出码和日志、启动配置持久化及快速面板选择。

另有真实 Windows 启动验证，覆盖含空格的程序路径、带空格的参数、日志输出和非零退出码。
