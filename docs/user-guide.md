# 使用说明

SuperBay 的日常操作都在这里：怎么选工作区、怎么找工具、怎么把启动方式调顺手，以及数据放在哪。

[项目说明](../README.md) · [目录规划指南](directory-planning.md) · [启动、终端与 Scoop](toolbox-features.md)

## 安装与启动

需要 Windows 10 / 11。从 [Releases](https://github.com/yanxinwu946/SuperBay/releases) 下载后直接运行，或双击 `start.vbs` 启动已构建的程序。

首次启动会打开引导页，说明工作区、分类和工具的推荐结构。点击「选择工作区目录」指向存放工具的根目录即可开始扫描；已有目录可以直接使用，**SuperBay 只读取，不移动任何文件**。

引导页关闭后，可以从空状态或「设置 → 工作区 → 目录规范」重新打开。

## 工作区

工作区是存放分类的那一层（例如 `D:\Tools`），不要直接选到某个工具内部。

- **添加**：左侧目录菜单 →「添加工作区」→ 选择目录，添加后自动保存。
- **切换**：用「当前工作区」限定搜索范围，或用「全部工作区」一起搜索所有已保存的工作区。
- **浏览**：侧栏默认显示一级分类，有子目录的项目可以展开；规范命名的分类以字母标识。
- **精简侧栏**：在「设置 → 工作区」启用「仅扫描规范命名目录」，只收录 `A-01` 或 `A-01-名称` 这样命名的第一层目录；也可以隐藏扫描范围内没有可启动项的目录。

目录怎么规划更省心，见[目录规划指南](directory-planning.md)。

## 搜索与浏览

`Ctrl+K` 聚焦搜索框，支持按**工具名称、拼音、标签、别名和笔记内容**查找。

- 用「全部类型」筛选结果；`Ctrl+Shift+F` 清除筛选条件。
- 列表和网格两种视图可随时切换，列表还分紧凑和舒展两种密度，都可调整排序。
- 方向键移动选择，`Ctrl` / `Shift` 多选，选中后可以批量固定或批量复制路径。
- 按 `Space` 预览条目，文本预览可以复制全文。
- 右键条目可以「在资源管理器中定位」「在此打开终端」或复制路径。

## 启动工具

选中工具后，右侧详情会列出「启动入口」。存在多个候选时点击「切换」选择，选择会被记住；路径优先相对于工具目录显示，悬停可查看完整路径。

| 方式 | 操作 |
| --- | --- |
| 直接打开 | 选中后按 `Enter` |
| 带参数启动 | `Shift+Enter`，或右键「带参数启动」 |
| 管理员权限 | `Ctrl+Enter` |
| 终端中运行 | 详情或右键「在此打开终端」，需先在设置中选好终端 |

「启动命令与标签」里可以自定义启动命令、标签、搜索别名，或固定为「总是以管理员身份启动」。启动入口留空时自动识别。

**启动方案**适合同一工具的多种用法（例如不同参数或不同子命令）：保存名称、命令和参数后，运行时再填具体值。**运行环境**可以为工具绑定 Scoop 中的 Python、Node.js 或 Java 版本。

外部终端、启动方案占位符、Python 后端和 Scoop 管理见[启动、终端与 Scoop](toolbox-features.md)。

## 笔记

右侧详情底部可以直接写笔记，编辑区至少显示两行，长笔记在区域内滚动。

- 停止输入或移开焦点自动保存，`Ctrl+S` 立即保存，`F2` 从列表直接进入编辑。
- 新笔记写入工具目录的 `NOTE.md`；目录里已有 `00.txt` 时沿用该文件。
- 笔记跟着文件走：目录改名或移动后仍然有效。
- 如果磁盘上的笔记被其他程序改动，SuperBay 会保留你当前编辑的内容并给出提示。

## 最近使用与固定

- 「最近使用」按最后启动时间排列。右键单项「从最近中移除」，或点标题旁的「清空最近」；移除后仍保留累计启动次数，再次启动会重新回到列表。
- 固定的工具单独成组，`Ctrl+D` 或右键即可固定 / 取消固定。

## 设置

顶栏齿轮或 `Ctrl+,` 打开设置。设置以独立弹窗显示，主工作台保持可见；按 `Esc` 或「返回工作台」关闭弹窗，不会退出 SuperBay。

| 分组 | 可以调整 |
| --- | --- |
| 外观 | 主题：浅色 / 深色 / 跟随系统 |
| 工具视图 | 列表或网格 |
| 启动 | 外部终端、终端参数模板、Scoop 安装目录 |
| 工作区 | 已保存工作区、目录规范、隐藏空目录、清理失效记录 |
| 托盘 | 关闭行为、唤起快捷键、启动时隐藏、开机自启 |
| 关于 | 版本与作者信息 |

| 快捷键 | 操作 |
| --- | --- |
| `Alt+S` | 从托盘召回 SuperBay（可在设置中更改） |
| `Ctrl+K` | 聚焦搜索 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+B` | 切换详情面板 |
| `Ctrl+Shift+F` | 清除筛选 |
| `↑` `↓` `←` `→` | 移动选择 / 展开收起 |
| `Enter` | 打开 |
| `Shift+Enter` | 带参数启动 |
| `Ctrl+Enter` | 以管理员权限启动 |
| `Ctrl+D` | 固定或取消固定 |
| `Ctrl+A` | 全选当前结果 |
| `Ctrl+C` | 复制选中项路径 |
| `Space` | 预览条目 |
| `F2` | 编辑笔记 |
| `Ctrl+S` | 立即保存笔记 |

## 托盘与退出

关闭主窗口时，SuperBay 会询问收起到托盘继续运行，还是退出程序。勾选「记住我的选择」后不再询问，也可以在「设置 → 托盘 → 关闭与退出」固定为「每次询问」「收起到托盘」或「退出程序」。

点击托盘图标或按 `Alt+S` 召回主窗口；右键托盘图标可以打开设置或退出。

- **唤起快捷键**：点击当前快捷键后直接按下新组合键，支持 Ctrl、Alt 或 Win 组合，`Esc` 取消。可以恢复默认或停用；若组合键已被其他程序占用，SuperBay 会提示重新设置。
- **启动时隐藏到托盘**：启动后直接留在托盘，不占用桌面。
- **开机自动启动**：登录 Windows 后自动在托盘中启动。

## 数据与迁移

工具文件和笔记始终留在原目录。设置、工具元数据和使用记录保存在本机：

```text
%LOCALAPPDATA%\SuperBay\
├── config\config.yaml    设置
└── config\data.db        工具元数据与使用记录
```

- 旧版 `%LOCALAPPDATA%\SuperGUI` 的数据会在首次启动时自动迁移到 `SuperBay`。
- 需要把数据放到别处（例如绿色版或源码目录）时，设置环境变量 `SUPERBAY_DATA_DIR` 指向目标目录；`start.vbs` 在源码目录已有 `config\` 时会自动这样做。
- 更换电脑：退出 SuperBay 后复制 `config.yaml` 与 `data.db`，工具目录和笔记单独迁移；Scoop 绑定的运行环境需要在新电脑重新安装。

**清理失效记录**：固定、标签、别名、启动命令、运行环境和最近记录按完整路径保存，外部改名或移动后不会自动跟随。「设置 → 工作区 → 维护 → 清理失效记录」可以删除这些记录，工具文件和笔记不受影响。目录只是临时不可用（例如移动硬盘未接入）时请不要清理。

## 常见问题

**工具没有被扫描出来？**
确认目录里有可识别的启动入口或工程标记，然后按 `F5` 重新扫描。脚本请放在对应工具目录内，不要直接放在打算作为分类的目录里。

**一个目录显示成了可展开的合集？**
同一目录下有多个各自带启动入口的工具子目录时，SuperBay 会把外层当作合集分类处理，子工具仍可单独启动。把某个工具单独移到一个完整文件夹即可恢复为独立条目。

**目录改名后固定和标签不见了？**
元数据按完整路径保存，改名或移动后不会自动跟随；笔记不受影响。重新固定一次，或先清理失效记录。

**快捷键没反应？**
组合键可能被其他程序占用或在设置中被停用。打开「设置 → 托盘 → 唤起快捷键」重新录制。

**托盘图标没出现？**
系统未能创建托盘图标时，托盘相关选项会显示为不可用；重启 SuperBay 或检查系统托盘设置后再试。
