# SuperGUI 使用说明

## 第一次使用

1. 启动 SuperGUI，选择存放工具的根目录，例如 `D:\Pentest`。应选择包含各个分类的那一层目录。
2. 在左侧选择分类，在中间搜索或选择工具，右侧查看命令、环境和笔记。
3. 点击“启动”。第一次使用先检查启动命令；发现多个入口时，点击“识别”选择正确入口。
4. 新增工具后会自动更新，也可以按 `F5` 重新扫描。

顶栏目录下拉菜单用于切换已保存的目录入口。工具目录可以放在任意磁盘，推荐与启动器程序分开放置。

## 目录推荐命名

分类推荐使用 **字母-两位编号-分类名称**，例如 `B-10-信息收集`。字母与编号方便文件管理器排序，SuperGUI 显示分类时会隐藏 `B-10-`，只显示“信息收集”。`A-工具箱` 也支持隐藏前缀；单独的 `01-工具箱` 不会自动隐藏编号。命名是整理建议，不是运行要求。

下面是一套可直接参考的分类：

```text
D:\Pentest\
├── A-00-字典\
├── A-01-工具箱\
├── B-10-信息收集\
│   ├── OneForAll\
│   │   ├── oneforall.py
│   │   ├── requirements.txt
│   │   └── NOTE.md
│   └── 域名枚举\
│       └── subfinder\
│           └── subfinder.exe
├── C-20-漏洞利用\
├── C-30-扫描器\
├── D-40-Web安全\
├── D-41-服务攻击\
├── E-50-移动安全\
├── F-60-内网渗透\
├── G-70-免杀\
├── H-80-代码审计\
├── I-90-杂项工具\
├── I-91-插件\
├── J-00-挖洞笔记\
├── J-01-靶场\
└── Z-99-归档\
```

按自己的工具数量删减即可，不必创建全部分类。编号建议留出间隔，便于以后插入新分类。

工具文件夹推荐保留项目原名，例如 `OneForAll`、`subfinder`，一项工具一个文件夹。需要同时保留多个版本时，可使用 `工具名-版本号`。自写脚本和启动脚本尽量使用简短英文名；中文分类可以正常使用，部分第三方工具对空格或中文路径支持有限时，可将该工具放到纯英文路径。

不要随意改动工具内部的文件夹结构。命令已经保存后再移动或重命名工具目录，需要重新检查命令及环境绑定。

## 分类层级与扫描

支持嵌套分类，默认扫描深度为 2，可在设置中调整，范围为 1–16。超过扫描深度的目录作为一个条目显示。

包含可执行文件、脚本或项目标记（如 `requirements.txt`、`package.json`、`.git`）的文件夹会识别为工具，并保持整体，不再拆成下级分类。因此，分类目录里尽量只放工具文件夹，把启动脚本放进对应工具目录。

普通目录可能展开为分类；只想将一个资料目录作为条目时，可通过扫描深度控制。空分类不会显示。隐藏目录及 `node_modules`、`__pycache__`、`venv`、`vendor`、`SuperGUI` 等目录会跳过。根目录直属的普通文件也可以显示。

## “编辑”和“配置”有什么区别

| 入口 | 用途 | 什么时候使用 |
| --- | --- | --- |
| 识别 | 查找并选择工具启动入口 | 第一次添加工具，或入口发生变化 |
| 编辑 | 修改默认启动命令和运行方式（cmd / powershell） | 希望以后直接点击“启动”就使用这条命令 |
| 配置 | 保存多套命令、追加参数、管理员选项及环境绑定 | 同一个工具需要不同启动方式 |
| 绑定环境 | 为当前工具选择运行环境 | 工具需要指定 Python、Java 或 Node 版本 |

例如，默认命令填写 `python oneforall.py`；在“配置”里分别保存“查看帮助”（追加 `--help`）和其他常用参数组合。在配置窗口选择对应配置后点击“启动”。保存配置不会替换工具的默认命令。

配置中的命令留空时使用工具默认命令。“运行环境”按钮会打开当前工具的环境绑定设置；勾选保存环境绑定后，配置会记住当前绑定。

## 日常操作

- 搜索：输入工具名称、标签或笔记关键词；可按 `Ctrl+K` 聚焦搜索。
- 快速启动：按 `Ctrl+P` 打开快速启动窗口。
- 启动：选中条目后按 `Enter`；`Ctrl+Enter` 管理员启动；`Shift+Enter` 带参数启动。
- 常用工具：按 `Ctrl+D` 固定或取消固定。
- 笔记：在详情面板编辑并保存，保存在工具目录的 `NOTE.md`；已有 `00.txt` 时沿用。普通文件条目不支持笔记。
- 退出：关闭窗口会收起到托盘，完全退出请使用托盘菜单“退出”。

## 备份与换电脑

通过“工具管理 → 备份与迁移”导出配置。备份包含目录设置、工具元数据、启动配置、环境绑定和使用记录，不包含工具程序和运行日志。工具目录与笔记需要另外复制，运行环境需要在新电脑安装。

源码运行的数据保存在项目 `config/`；打包版保存在 `%LOCALAPPDATA%/SuperGUI`。迁移后检查目录路径，以及自定义命令中写死的旧路径。
